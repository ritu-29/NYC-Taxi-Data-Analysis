# NYC Taxi Power BI Dashboard

## Overview

This dashboard provides a comprehensive analysis of NYC Yellow Taxi trip data for 2026. It focuses on understanding trip patterns, revenue performance, customer behavior, and operational efficiency using interactive visualizations.

## Tools Used

* Power BI
* DAX
* Data Modeling
* Data Visualization

## Key Performance Indicators (KPIs)

The dashboard includes the following calculated measures:

* **Total Trips** – Total number of taxi trips analyzed
* **Total Revenue** – Total fare generated 
* **Total Tips** – Total tip amount collected
* **Average Fare** – Average fare per trip
* **Average Distance** – Average trip distance
* **Average Duration** – Average trip duration
* **Average Passengers** – Average number of passengers per trip
* **Average Speed** – Trip efficiency (distance/duration)
* **Revenue per Trip** – Average revenue generated per trip
* **Revenue per Passenger** – Revenue efficiency per passenger
* **Tip %** – Percentage of tips relative to fare
* **Long Trip %** – Percentage of trips classified as long-distance

## Visualizations

* Revenue Analysis
* Trip Distance Distribution
* Payment Type Distribution
* Passenger Count Analysis
* Pickup and Drop-off Location Analysis
* Time-based Trip Trends

## Data Preparation

* Cleaned raw NYC taxi data using Python (Pandas)
* Handled missing and invalid values
* Removed outliers (e.g., extreme trip distances)
* Created new features such as trip duration
* Built DAX measures for KPI calculations

## Key Insights

* Generated total revenue of **$66.11 million**
* Credit card payments dominate transaction methods
* Identified patterns in trip distance and fare distribution
* Observed passenger behavior and trip frequency trends
* Analyzed location-based pickup and drop-off activity

## Dataset

NYC Yellow Taxi Trip Records (2026)
